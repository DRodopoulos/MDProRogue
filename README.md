# MDProRogue

A single-player Yu-Gi-Oh! roguelite built on [MDPro3](https://github.com/electrolyteJ/MDPro3). Take a deck through adventures across a branching map, collect cards, relics and partner engines, and face anime duelists, from Duelist Kingdom up to the Grand Championship.

## Download

**[Latest version](https://github.com/DRodopoulos/MDProRogue/releases/latest)**: under *Assets*, download `MDPRO_ROGUE-v<version>-win64.zip`.

1. Unzip it anywhere. Windows 10 or 11 (64-bit) is needed, plus about 10 GB of free space for the downloads below.
2. Start `MDPro3.exe`.
   - Windows may say "Windows protected your PC", because the game isn't code-signed. Click **More info**, then **Run anyway**.
3. **First start:** the game downloads the Master Duel assets (about 5.5 GB). Then the main menu offers **DOWNLOADS**: the card data (about 100 MB, needed for duels) and the card artwork (about 2 GB). Downloads continue in the background and pick up where they stopped.

## Updates

When a new version is out, the game offers it on the main menu. **Update** downloads it, closes the game, puts the new files in place and starts the game again. Your progress, decks and downloads stay.
